# tenchat-parser

Парсер постов [TenChat](https://tenchat.ru/) по списку хештегов. Для каждого поста собирает заголовок, автора, дату, ссылку и количество просмотров; результат сохраняется в CSV с автоматической дедупликацией.

## Что умеет

- Проходит по страницам `https://tenchat.ru/hashtag/{тег}` из встроенного списка
- Для каждого поста извлекает: `title`, `author`, `date`, `url`, `views`, `hashtag`
- Сохраняет результат в `posts_YYYYMMDD_HHMMSS.csv` в текущей директории
- Убирает дубли — если один пост попал в несколько тегов, в файл он попадёт один раз (ключ — URL поста; в колонке `hashtag` остаётся первый встреченный тег)
- Делает случайную паузу 2–3 секунды между запросами

## Требования

- Python 3.10+
- `requests`, `beautifulsoup4`

## Установка

```bash
git clone https://github.com/DmitryChuchulin/tenchat-parser.git
cd tenchat-parser
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python3 tenchat_parser.py
```

В процессе работы в stdout будет прогресс по каждому хештегу:

```
[1/30] #разработка → https://tenchat.ru/hashtag/разработка
    постов на странице: 18, новых: 18
[2/30] #itразработка → https://tenchat.ru/hashtag/itразработка
    постов на странице: 20, новых: 17
...
```

По окончании появится файл вида `posts_20260421_143012.csv`.

## Настройка

Все параметры заданы константами в начале `tenchat_parser.py`:

| Константа      | Назначение                                            |
|----------------|-------------------------------------------------------|
| `HASHTAGS`     | Список хештегов для обхода                            |
| `MIN_DELAY`    | Минимальная пауза между запросами, секунд             |
| `MAX_DELAY`    | Максимальная пауза между запросами, секунд            |
| `TIMEOUT`      | Таймаут HTTP-запроса, секунд                          |
| `HEADERS`      | HTTP-заголовки (User-Agent, Accept-Language и т. п.)  |
| `CSV_FIELDS`   | Порядок колонок в выгрузке                            |

## Формат CSV

| Поле      | Описание                                                    |
|-----------|-------------------------------------------------------------|
| `title`   | Заголовок поста (либо текст ссылки, если заголовка нет)     |
| `author`  | Имя автора поста                                            |
| `date`    | ISO-дата из атрибута `<time datetime="…">` или текст даты   |
| `url`     | Абсолютная ссылка на пост                                   |
| `views`   | Количество просмотров (целое число в виде строки)           |
| `hashtag` | Первый хештег, на чьей странице пост был обнаружен          |

## Замечание про селекторы

TenChat — клиентский SPA на React, и разметка ленты периодически меняется. Скрипт использует несколько стратегий поиска: `<article>`, затем атрибуты вида `data-testid*="post"`, `class*="post-card"`, `class*="feed-item"` и так далее. Если селекторы устареют, правьте функции `_find_post_containers`, `_find_post_link`, `_find_author`, `_find_date`, `_find_views` в `tenchat_parser.py`.
